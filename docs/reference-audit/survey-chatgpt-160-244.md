# Survey: ChatGPT web Mar 2026, indices 160 to 244 (85 screens)

Pack: "ChatGPT web Mar 2026". Source: `.reference/chatgpt/ChatGPT web Mar 2026 N.png`, N = 160..244. All 85 indices were viewed on contact sheets 11-16. About 45 were opened at full size (Mobbin footer cropped to 1920x1200). The rest were reviewed in 2x2 and 3x3 montages at 40-50% scale.

## Scale used (read this first)

- Every image is 1920x1320. After removing the 120 px Mobbin footer, the app viewport is 1920x1200.
- Measured raw widths: sidebar 330 px including a 1 px border at x=329, and the chat composer 977 px.
- I assumed ChatGPT's sidebar is 260 CSS px and its thread column is 768 CSS px. Those are my priors, not measured here. They give 1.269 and 1.272, so I use a scale of about 1.27, which implies a viewport of about 1512 CSS px.
- Two more checks agree with 1.27. The settings modal is 865x763 raw, about 681x601 CSS. The confirm dialog is 570 raw, about 449 CSS.
- Convention: "raw" means measured screenshot pixels. "CSS" means raw divided by 1.27, which is derived and approximate. "(est.)" means inferred, not measured. Measuring specialists should confirm the scale with one more known element.
- The slice contains no RTL screen. Arabic appears only as a menu entry in the language list (188), so RTL mirroring cannot be measured from this slice.
- The slice contains no data-dense multi-column sortable table. The closest are 212/213 (a 2-column modal table) and the 187/186 row lists.
- The slice contains no upload-progress, confidence-score or chart UI.
- Screens show a Mobbin demo account email. It is not repeated in this file.

## Observations

1. **App shell is a quiet 260 CSS px sidebar plus open canvas.** The sidebar is 330 raw with a 1 px border, a tint one step off the canvas (#f8f8f8 against #ffffff, or #181818 against #212121), and a 36 CSS row pitch with filled-pill active state. There are no per-item fills when idle and no icon colour. The top nav items have icons about 22 raw. Evidence: 238, 165, 163, 184, 186.
2. **Top bar is borderless and transparent.** There is a title dropdown on the left ("ChatGPT ⌄"), a pale-indigo pill chip centred, and icon-only actions on the right ("Share" and "…" on project pages, a gear on the Apps page). No divider or shadow separates the bar from content. Evidence: 238, 163, 184, 186, 172.
3. **Hero composer pattern.** A single centred pill (about 769x57 CSS) holds a leading +, placeholder text, a mic, and a solid circular send or voice button. The heading above is regular weight, about 27-28 CSS, and sits above the vertical centre. There are no cards or suggestion chips on home. Evidence: 238, 165, 183, 169, 172.
4. **Chat thread anatomy.** The user message is a right-aligned dark pill (#303030 in dark mode). The assistant text is unboxed in a 768 CSS column. Headings are semibold with emoji, bullets use bold lead-ins, and a 1 px rule (#464646) separates sections. A three-tile image row has small gaps and rounded corners. A round scroll-to-bottom button floats above the docked composer, with a 12-13 CSS disclaimer line beneath. Evidence: 184, 192.
5. **Settings modal is a two-pane card.** It is 680x600 CSS, with a 180 CSS left nav tinted #f9f9f9 (X close top-left, 36 CSS rows, 20 px icons, filled active pill) and a right pane with an 18 CSS title over a hairline. Padding is about 16 CSS. Evidence: 173, 174, 175, 177, 178, 180, 182.
6. **Setting rows are dense and flat.** Row pitch is 60 CSS for single-line rows. The 14 CSS black label is left. The right side holds a control. Under the label sits an optional 12-13 CSS gray description (16 CSS line height, about 60% width). Rows are separated by 1 px #f1f1f1 hairlines, with no card per row. Evidence: 173, 174, 177, 178.
7. **Control vocabulary inside rows.** The right-hand control is one of these:
   - a borderless value plus chevron-down trigger ("System ⌄", "Push, Email ⌄");
   - an outline pill button, 36 CSS tall ("Manage", "Archive all", "Export", "Log out");
   - a destructive outline pill with red text and border ("Delete all", "Log out all");
   - a toggle switch;
   - a value plus chevron-right drill-in ("On ›", "****** ›", "Add ›").

   There are no boxed selects. Evidence: 177, 178, 173, 182, 203.
8. **In-pane section headings.** Sub-sections ("Multi-factor authentication (MFA)", "About you", "Family members", "Safety notifications", "Memory ⓘ") use about 18 CSS regular-weight text over a hairline. Help icons are small outlined circles. Evidence: 178, 175, 203, 222.
9. **Multi-select popover from a row trigger.** A small white popover under the trigger lists channels as "Push [toggle]" and "Email [toggle]". Blue switches mean on. The trigger label updates to the summary ("Push, Email", "Email", "Off"). This is a clean pattern for per-party or per-field visibility. Evidence: 195, 196, 197, 198, 199, 174.
10. **Dropdown menus are white cards on a hairline border.** They have a 1 px #ddd border, a soft shadow, a 36 CSS row pitch, and about 14 CSS text. The selected option has a right-aligned check. Option lists may have two-line items (name plus gray description: Default / Professional / Friendly), a divider after pinned options (Auto-detect, English), and a scrollable tall list. Evidence: 163, 181, 188, 189, 200, 206, 209.
11. **Account menu from the sidebar footer.** It opens upward as a card about 315 raw wide. It has a name and handle header, a hairline, items with 18 px icons (Upgrade plan, Personalization, Settings), another hairline, then "Help ›" (submenu chevron) and "Log out" last. Evidence: 165.
12. **Confirm dialog anatomy.** About 448 CSS wide. Regular-weight title (about 18 CSS), a 14 CSS body that bolds the affected item name inside quotes plus an underlined "Learn more", and right-aligned buttons: outline pill "Cancel" and solid red pill "Delete" (#df2e2b). Logout instead uses two stacked full-width pills (black "Log out", outline "Cancel"). The page behind is dimmed and blurred. Evidence: 210, 170, 229.

The settings modal stays visible but dimmed and blurred behind. Archived-chats is wider (about 1020 CSS). Evidence: 212, 216, 219, 223, 229.

Inputs inside dialogs are low-radius rectangles (about 6-8 CSS, est.) of about 400x38 CSS. Radios list a choice ("My parent or guardian" / "My child"), and selecting one reveals a longer explanatory paragraph. Footer is Cancel (outline) plus a primary pill that is gray #c4c4c4 when disabled and black when valid. Instructions use bold "Step 1:" / "Step 2:" prefixes. Evidence: 216, 217, 219, 220, 221, 223, 224.

A blocked variant says to log in again and offers a black full-width "Refresh login". Evidence: 228, 229, 227.
