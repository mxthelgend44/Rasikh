The files `data/osm-*.json` and OSM-derived datasets in `models/osm-*.json`
contain data derived from **OpenStreetMap contributors**. They are distributed
under the **Open Data Commons Open Database License 1.0 (ODbL)**.

- Attribution: © OpenStreetMap contributors
- Source and attribution guidance: https://www.openstreetmap.org/copyright
- License: https://opendatacommons.org/licenses/odbl/1-0/
- Complete query, retrieval date, OSM base timestamp, and source/derived hashes:
  `models/osm-provenance.json`.

Retain attribution and license links when displaying recommendations. Keep the
ODbL notice with redistributed derived data. This data notice does not replace
the applicable license for application source code.

The unrelated rental-index research cache and artifacts are gitignored and are
not included in the releasable OSM model. That publisher has not stated a reuse
license in its ArcGIS item metadata; public API access does not establish reuse
permission or official endorsement.
